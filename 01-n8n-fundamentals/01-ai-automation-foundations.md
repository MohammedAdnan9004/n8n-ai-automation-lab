## 2. Concepts Learned

### Artificial Intelligence (AI)

Artificial Intelligence allows software systems to perform tasks that normally require human intelligence, such as understanding text, generating content, classifying information, and making recommendations.

### Automation

Automation is the process of executing repetitive tasks using predefined rules with minimal manual effort.

**Example:** Automatically sending a confirmation email when a user submits a form.

### AI Automation

AI Automation combines traditional automation with AI models to handle tasks that require understanding, interpretation, or decision-making.

**Example:** Reading an incoming customer email, identifying its intent using AI, and routing it to the appropriate team.

### AI Agents

AI agents are systems that use AI models to interpret goals, decide on actions, and interact with available tools.

Unlike a fixed workflow, an agent can select different actions depending on the request and the tools it has access to.

### What is n8n?

n8n is a workflow automation platform that connects applications, APIs, databases, and AI services through nodes.

It supports:
- Visual workflow development.
- Event-based and scheduled triggers.
- API integrations and webhooks.
- Conditional execution and data transformation.
- AI model and agent integrations.
- Self-hosted deployment.

## 3. n8n vs Zapier vs Make

| Tool | Main Characteristics |
|---|---|
| n8n | Visual workflows, custom code, API flexibility, self-hosting options |
| Zapier | Managed automation with a large application integration ecosystem |
| Make | Visual scenario builder with routing and data manipulation features |

The best tool depends on the workflow complexity, hosting requirements, technical experience, and budget.
