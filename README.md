# n8n AI Automation Lab 🚀

### Hands-on AI Automation | n8n Workflows | AI Agents | API Integrations

Hi, I'm **Adnan Khan**, a Full Stack Developer exploring AI Engineering and workflow automation.

This repository contains my practical implementations, experiments, and projects using **n8n and AI technologies**. My goal is to understand how to build useful, reliable, and production-ready automation workflows by solving real-world problems.

I use this repository to document what I build, how each workflow works, the challenges I face, and what I learn along the way.

---

## 🎯 What I'm Learning

- **n8n Fundamentals:** Workflow creation, nodes, triggers, expressions, and execution flow.
- **API Integrations:** REST APIs, webhooks, OAuth authentication, and external services.
- **Workflow Logic:** IF, Switch, Merge, loops, conditional execution, and error handling.
- **Data Transformation:** Code nodes, JavaScript, JSON parsing, and data cleaning.
- **AI Agents:** Building AI-powered workflows using LLMs and AI agent nodes.
- **RAG Systems:** Document-based question answering, retrieval, and reducing chatbot hallucinations.
- **Local AI Models:** Exploring Ollama and locally hosted LLMs.
- **Database Integration:** PostgreSQL, Supabase, and persistent workflow data.
- **Human-in-the-Loop:** Approval workflows, validation, and controlled AI execution.
- **Business Automation:** Email workflows, Google Sheets, lead generation, and task automation.
- **Production Readiness:** Security, error handling, monitoring, and workflow reliability.
